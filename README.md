# 100 Indie Games

100 successful games made by solo developers and tiny teams (1–3 people), for the FPT AI Sharing talk.

- Live: https://indie-games-100.pages.dev
- Data: `public/games.json`, art in `public/art/`
- Deploy: every push to `main` deploys to Cloudflare Pages via GitHub Actions. Requires repo secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
